An entry for make.fun's One Emoji, One Dream Vacation bounty ($2 in USDC): a program that writes exactly one emoji to `/output/entry.txt`.

The emoji is 🌋 — a volcano. Not a beach, not a plane: Iceland at dawn, lava glowing against black sand, a hike up to a crater lake. A trip with a pulse, vivid at a glance, specific to one kind of dream, and surprising enough to make a stranger want to book the flight.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
